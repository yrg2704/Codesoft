Codesoft — Python Mini Projects

A collection of Python mini projects developed to practice programming fundamentals, problem-solving, and GUI development.

Projects

1. Calculator

A simple calculator application implemented in Python.

File: "calc.py"

2. Contact Book

A Python-based contact book application for managing contacts.

File: "contact_book.py"

3. Password Generator

A Python program for generating random passwords.

File: "password_generator.py"

4. Rock Paper Scissors GUI

A graphical Rock Paper Scissors game implemented using Python.

File: "rps_gui.py"

5. To-Do GUI

A graphical To-Do application built with Python.

File: "todo_gui.py"

Technologies

- Python
- GUI Development
- Problem Solving
- Basic Programming Concepts
- Randomization
- File Handling

Getting Started

Clone the repository

git clone https://github.com/yrg2704/Codesoft.git
cd Codesoft

Run a project

For example:

python calc.py

You can run any of the Python files individually.
